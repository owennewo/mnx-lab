# Contributing

MNX Lab is licensed under the GNU AGPL-3.0 **and** offered under commercial licences by its
copyright holder (dual licensing; see [NOTICE.md](NOTICE.md)). Dual licensing is only possible
while the copyright holder can license every part of the code both ways.

So **outside contributions need a signed contributor licence agreement** that grants the
copyright holder the right to relicense them. No such agreement exists yet, so **pull requests
from outside contributors are not accepted for now.** If you would like to contribute, open an
issue or contact the copyright holder through GitHub ([github.com/owennewo](https://github.com/owennewo));
a standard agreement (such as the Harmony agreements or an adapted Apache CLA) will be put in
place first. A DCO sign-off alone is not enough, because it does not grant relicensing rights.

Bug reports and ideas as issues are welcome at any time.
