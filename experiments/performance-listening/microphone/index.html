About this test

F-006 adds explicit fundamental support to F-003. It improves bass recovery in synthetic tests but still produces false detections. Recording and detection stay in this browser; nothing is uploaded. Each take is limited to five minutes. Download a take before starting another or closing the page.

The listener uses 22,050 Hz audio, a 186 ms analysis window and an 11.6 ms hop. Browser capture and buffering add delay. The stream shows when a note was detected, not a claim about your timing accuracy. Input processing is requested off; actual microphone settings are included in the download.
